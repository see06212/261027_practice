# Project instructions

- This is a Vite project that uses vanilla JavaScript. Keep the implementation framework-free unless the user explicitly asks otherwise.
- Keep HTML, CSS, and JavaScript in separate files. Put CSS and JavaScript files in the `src/` directory; do not put inline styles or scripts in HTML.
- Install and manage JavaScript libraries as npm dependencies. Do not add libraries through CDN script or stylesheet links.
- The project is uploaded to GitHub and deployed with Netlify. Keep changes compatible with the existing Vite build and Netlify deployment setup.
